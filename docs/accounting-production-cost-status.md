# Source-backed production cost and root lot valuation — 4 November 2026 Jakarta

Isolated staging `pkgrqalpazhwdcxmthvb` only. No real opening or amounts invented; production/main rollout not authorized.

## Implemented

- Owner Audit Biaya HPP panel supports actual **paid** labor/overhead source allocation and root batch completion. Each inspection is followed by explicit confirmation of a fresh, five-minute purpose-signed review. Server Auth, active Owner, exact staging origin/project, service-only SECURITY INVOKER RPC; no browser access to private tables.
- A nonpurchase expense must be explicitly classified entirely as production labor or overhead. Labor accepts Gaji; overhead accepts Utilitas/Sewa/Maintenance/Operasional Lain, with Owner confirmation that this is not raw material, equipment, drawings or period expense. Mixed-purpose payments need a separate classification workflow; unpaid costs require accruals, which are not implemented here.
- First allocation recognizes the original payment once: Dr1290 production-cost clearing / Cr cash-bank, using actual source amount/date. Batch portions then Dr1215 WIP / Cr1290. One source can serve several batches, one allocation per source/batch, never beyond its remaining amount. Unallocated clearing is temporary reconciliation, not approved final profit; its nonzero balance prevents period close.
- Period expense and production expense mappings are mutually exclusive under the same locked source expense. Paid source rows become immutable, and correction/reversal still needs a separate reviewed workflow. No new physical inventory/product stock movement or source cashbook row is generated by journal posting.
- Completion requires a Finished batch, all active material usages valued, explicit labor/overhead completeness (zero requires an explicit evidence-backed declaration), and exact root output stock receipts. DIRECT good+reject reconciles to split quantity; FROZEN retains its initial quantity. Derived frozen splits are excluded from new production cost.
- Owner chooses normal loss absorbed by usable units, or separate abnormal-loss cost supported by actual rejects. Positive verified per-root allocations plus separate reject cost must equal material + labor + overhead exactly. Journal Dr1220/1230 products/frozen, Dr6070 abnormal loss if applicable, Cr1215 total WIP. Original material WIP quantities/values are released without consuming raw stock again. Lot totals are exact; displayed per-unit values are informational rounded ratios.
- Completed root splits and their inbound stock receipts are immutable. Later frozen-derived conversion and outbound operational movements remain possible, but their financial cost transfer is **not** implemented by this release. Initial lot values are not claimed as a fully reconciled current stock valuation. Sold COGS and final profit remain unavailable.
- Operation retries return the original journal; changed replay, stale source/allocation balances, insufficient source amounts, duplicate allocations, mismatched output and closed/unsupported periods fail atomically. Unallocated payment pools and incomplete Finished-batch valuation block period closure.
